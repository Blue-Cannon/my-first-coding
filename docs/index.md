# My First Coding

My First Coding is a free, online learning platform that teaches computer programming and software development.
My First Coding helps you to learn anything you want to do like Programming Language or Markup Language in Everytime, Everywhere. You can start Level to Level Up. Inspired by freeCodeCamp and Khan Academy. It is developed by Blue-Cannon in GitHub, a organization where indie devs lives on.
