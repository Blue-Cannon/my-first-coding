much easy to learn. Python was developed by Guido Van Rossum. Guido Van Rossum is a Dutch Programmer

## Mattered
Van Rossum designed Python around simplicity, readability, and versatility. The idea was code that looks almost like English and is easy to learn, which is why it exploded in web development, data science, and artificial intelligence.

## Begin
It started as a Christmas hobby project.

Late 1989, Guido van Rossum was working at CWI — Centrum Wiskunde & Informatica in Amsterdam, Netherlands. He had helped build a teaching language called ABC earlier in the 80s. ABC was super readable and beginner-friendly, but it failed because it was closed, couldn't be extended, and couldn't talk to the operating system.

The CWI office was closed for the Christmas holidays. Guido had nothing to do and wanted a project that would keep him occupied over the break.

He thought: what if I make a successor to ABC that fixes all its flaws, but keeps its readability? A language that:
1. Is as easy as ABC, but extensible 2. Can interface with the Amoeba operating system his group was working on 3. Borrows the best from other languages — modules and exceptions from Modula-3, some C syntax, and Unix power 
He started coding in December 1989. He was sitting at home, and because he was a fan of Monty Python's Flying Circus, he decided to call this new secret project Python.

It wasn't meant to be serious at first. The goal was just to have fun building something.

Timeline:
- Dec 1989 - Feb 1991: Built in his spare time 
- Feb 1991: First public release, Python 0.9.0, posted to the newsgroup alt.sources. It already had functions, exception handling, and a module system.   
- Jan 1994: Python 1.0 adds lambda, map, filter, reduce • Oct 2000: Python 2.0 brings list comprehensions and a real community development process 
- Dec 2008: Python 3.0, a big clean-up that broke backwards compatibility to make the language better long-term 
From a one-man Christmas hack to keep from being bored, to the language that now powers AI, YouTube, Instagram, and most of the science you use — that's Python's beginning.

He famously said he wanted to bridge the gap between C and shell scripting. Something powerful like C, but easy to write like a shell script.
