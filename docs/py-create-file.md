## Breakdown 
`print` is a built-in command or code that tells
the computer to say the inside of the print.

`()` is a symbol that tells the Python to tell the `print`
say this.

`""` same purpose of the symbol `()`

`Hello, World!` it tells the computer to say this string 
like `print` say Hello, World!.
