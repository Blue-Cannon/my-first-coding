## Welcome!
Welcome our little explorer! Setup by using a phone,
don't buy a expensive device that's setup My First Coding.

## Steps
### On Android 
1. Open Chrome app.
2. Tap the **Address URL Bar** and type `https://blue-cannon.github.io/my-first-coding`
3. Find the Link "GetS"

### On iOS
1. Open Safari
2. Tap the **Address URL Bar** and type `https://blue-cannon.github.io/my-first-coding`
3. Find the Link "GetS"
